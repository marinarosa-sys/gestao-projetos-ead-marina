Conceitos de Arquitetura de Software - Gestão de Projetos (SENAI EAD)

Este projeto é um site estático desenvolvido para a disciplina de Gestão de Projetos do curso de Análise e Desenvolvimento de Sistemas (SENAI EAD), sob orientação do professor Wesley Fioreze.

O objetivo do site é apresentar análises de conceitos clássicos de arquitetura de software baseados nos artigos de Martin Fowler, abordando suas vantagens, desvantagens e seus impactos na gestão de projetos.

📌 Tópicos Abordados

Microsserviços: Pré-requisitos e impactos operacionais.

🤖 Declaração do Uso de Inteligência Artificial

Declaramos que ferramentas de Inteligência Artificial foram utilizadas no desenvolvimento deste projeto com finalidades específicas:

Claude (Anthropic): Utilizado para gerar a estrutura base e o layout do site (HTML/CSS), servindo de ponto de partida para nossas personalizações e ajustes.

Gemini (Google): Utilizado pontualmente para a revisão textual — garantindo maior coesão e coerência na escrita dos resumos (sem a elaboração de respostas ou análises completas do conteúdo) — e também para o auxílio no desenvolvimento da documentação deste README.md.
